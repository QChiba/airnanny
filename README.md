# airnanny

[English version](README.en.md)

Интеграция Home Assistant для бризеров Atmeex AirNanny (проверена на A7) и небольшая консольная утилита для облачного API Atmeex.

У бризера нет локального API: он держит соединение только с `api.iot.atmeex.com`, поэтому всё управление идёт через облако.

## Интеграция Home Assistant

### Перед началом

Интеграция видит только те устройства, которые уже есть в вашем облачном аккаунте Atmeex. Сначала установите официальное приложение **Atmeex**, войдите в него и добавьте бризер (вместе с комнатой, если приложение попросит). Как только устройство появится в приложении, оно есть в облаке Atmeex, и интеграция его найдёт.

В Home Assistant входите с тем же логином, что и в приложении. Вход по email и паролю и вход по телефону с SMS — это разные способы: если войти по номеру телефона, которого приложение не знает, будет создан новый пустой аккаунт.

### Установка через HACS

1. В HACS откройте меню ⋮ → **Пользовательские репозитории** (Custom repositories).
2. Добавьте `https://github.com/QChiba/airnanny` с типом **Интеграция** (Integration).
3. Найдите **Atmeex AirNanny** в HACS, скачайте и перезапустите Home Assistant.
4. Откройте Настройки → Устройства и службы → Добавить интеграцию → **Atmeex AirNanny** и войдите по email и паролю или по телефону с SMS.

### Ручная установка

1. Скопируйте папку `custom_components/atmeex` в папку `custom_components` в каталоге конфигурации Home Assistant.
2. Перезапустите Home Assistant.
3. Откройте Настройки → Устройства и службы → Добавить интеграцию → **Atmeex AirNanny** и войдите по email и паролю или по телефону с SMS.

### Сущности

Названия сущностей в Home Assistant отображаются на английском.

| Сущность | Что делает |
|---|---|
| Fan | Включение и выключение. При выключении заслонка закрывается (рециркуляция), как кнопкой питания на пульте; при включении возвращается прежнее положение заслонки |
| Fan speed | Ползунок скорости 1–7 |
| Heater / Heater temperature | Включение нагрева и целевая температура 10,0–30,0 °C с шагом 0,5° (пока нагрев выключен, температура запоминается) |
| Humidifier | Ползунок 0–3, 0 — выключено |
| Air intake | Fresh air (приток) / Mixed (смешанный) / Recirculation (рециркуляция) — эти режимы заодно включают вентилятор; Supply air valve (приточный клапан: вентилятор выключен, заслонка открыта, как в приложении) |
| AutoNanny, Night mode | Переключатели режимов; при их выключении возвращается скорость, которую режим перезаписал. Ночной режим сразу снижает скорость до 1 (работающего ночного расписания в устройстве нет) |
| CO2, Room temperature, Inlet air temperature, Humidity, Actual fan speed, Water tank empty | Датчики: CO2, температура в комнате, температура приточного воздуха, влажность, фактическая скорость, пустой бак для воды |
| Fan throttled | Включается, когда бризер больше минуты сам работает медленнее заданной скорости (например, при холодном приточном воздухе) |
| Online | Связь с облаком |

## Консольная утилита

```sh
python3 atmeex.py login        # сохраняет токены в ~/.config/atmeex/tokens.json
python3 atmeex.py status       # заданные настройки и фактическое состояние
python3 atmeex.py watch [secs] # записывает изменения в watch.log
python3 atmeex.py get /devices/<id>
```
